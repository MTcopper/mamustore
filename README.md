# MAMU STORE - Sneaker & Gear Showroom

Website giới thiệu và quản lý kho hàng Sneaker & Gaming Gear chính hãng phong cách Luxury Minimalist Boutique.

- **Chế độ Khách xem:** Giao diện tối giản, 4 góc chụp sắc nét chuẩn Studio, đổi size thông minh 4 hệ (US | UK | EU | CM).
- **Chế độ Dev Mode:** Quản lý giá vốn nhập kho, giá bán ra, lãi trên từng đôi, tỷ suất lợi nhuận, xuất bán và nhập hàng nhanh 1 chạm.
